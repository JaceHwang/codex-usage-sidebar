# Codex Usage Sidebar v0.1.2

Version 0.1.2 replaces estimated titlebar positioning with a direct semantic anchor to Codex's
native Open Location control.

## Highlights

- Exactly one compact quota control in the content header.
- Exact 8-point gap to Open Location across left, right, and bottom pane changes.
- Cached accessibility element sampled every 0.1 seconds during window movement and resizing.
- Hover details for plan, period, Credits, aggregate Bank availability, and every Bank entry with
  status and expiry.
- Continuous green, orange, and red percentage coloring.
- Isolated `CodexHome` authorization through the official `codex login` flow.
- Stable signing selection and deterministic CI signing requirement.
- 71 Swift tests plus shell integration, signing, provenance, and repository validation.

## Install or update

```bash
codex plugin marketplace add JaceHwang/codex-usage-sidebar
codex plugin add codex-usage-sidebar@codex-usage-sidebar
```

Start a new Codex task, then authorize the companion's isolated home once:

```bash
plugin_home="$HOME/Library/Application Support/CodexUsageSidebar/CodexHome"
env CODEX_HOME="$plugin_home" codex login
env CODEX_HOME="$plugin_home" codex login status
```

Enable **Codex Usage Sidebar** in macOS Accessibility and verify:

```bash
"$HOME/Library/Application Support/CodexUsageSidebar/sidebar-control.sh" status
```

The intended diagnostic contains:

```text
anchor=openLocation placement=content-header
anchor_scan=...cached:true,source:openLocation
```

## Upgrade notes

The previous sidebar/footer state stack and global event monitors are gone. The companion remains
external to Codex, so official app upgrades do not overwrite it. Existing users can run the normal
marketplace update, start a new task, and use the one-command repair if needed.

The release app is the exact ad-hoc-signed artifact produced and tested by GitHub Actions. Its
source commit and hashes are recorded in the plugin's `assets/PROVENANCE.json`.
