# Codex Usage Sidebar v0.2.3

Version 0.2.3 prevents the quota control from overlapping native Codex titlebar controls while the
right pane is dragged through intermediate widths.

## Highlights

- Prefers the existing exact 8-point Open Location placement when that frame is free.
- Slides left to the nearest complete free slot when a native button occupies the preferred frame.
- Treats static title text as a hard barrier rather than covering or crossing it.
- Moves immediately to the existing safe right-side fallback when no complete local slot remains.
- Distinguishes an intentional resolved fallback from a transient incomplete accessibility scan,
  so stale cached anchors cannot override a necessary move.
- Scans the indicator's full horizontal reach while pruning everything below the 46-point
  titlebar, reducing the reproduced scan from 769 visited elements to 54.
- Ignores 1-point-high content frames clipped against a fullscreen window's top edge, so closing
  the right pane cannot turn invisible conversation geometry into a false title barrier.
- Re-runs collision detection on every 0.1-second placement tick and reads labels only after a frame
  qualifies as meaningfully visible titlebar geometry.

## Root cause

The previous accessibility walk discarded every branch left of the window midpoint. The quota
control is 164 points wide and can extend left of that midpoint, so a native Open Location subtree
inside the candidate frame could be skipped. The resolver then accepted a generic anchor whose
frame overlapped Open Location.

A second fullscreen-only failure came from Chromium exposing offscreen conversation content as
1-point-high frames clipped to the top window edge. Those degenerate frames passed the titlebar
band check, appeared to block the preferred slot, and forced the fixed fallback over Open Location
when the right pane was closed. The resolver now requires occupied titlebar items to have a
meaningfully visible height.

## Validation

The release adds regression coverage for nearest-slot collision resolution, static title barriers,
immediate fallback, stale-cache replacement, multiple Open Location candidates, horizontal scan
reach, titlebar-only vertical pruning, and fullscreen clipped-content filtering. The complete Swift
suite passes 133 tests. Real captures of both adaptive states are included in the English and
Chinese READMEs.

The distributed app is promoted from the exact successful GitHub Actions artifact and bound to its
source commit and hashes in `assets/PROVENANCE.json`.
