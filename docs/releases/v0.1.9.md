# Codex Usage Sidebar v0.1.9

Version 0.1.9 makes reinstall diagnostics truthful, preserves the companion's Accessibility code
identity, and adds the finalized quota-card version and progress visuals.

## Added

- A compact transparent blue-outline version badge beside the quota-card title, sourced from
  `CFBundleShortVersionString` so UI and installed code stay synchronized.
- A fixed red-to-orange-to-green progress spectrum clipped to the live remaining percentage.
- Exact palette anchors at 10% red, 49% orange, and 100% green for both compact and hover
  percentage labels.
- Sanitized runtime-state reporting from the active LaunchAgent, including PID, version, anchor,
  indicator frame, and timestamp.

## Fixed

- Plugin repair re-signs the copied app with the stable local signing identity when available,
  preventing a reinstall from invalidating Accessibility trust and reverting to fallback placement.
- Payload matching uses a source fingerprint, so the intentional installer signature does not look
  like stale executable content.
- The full quota-card title, smaller raised version badge, percentage, and progress bar retain their
  native spacing in light and dark themes.

## Verification

- The pure Swift suite covers the 10%, 49%, and 100% palette anchors and ordered gradient stops.
- Installer tests cover stable signing, payload fingerprints, repair, status, and malformed inputs.
- CI rebuilds the ARM64 companion with macOS SDK 26.5, validates the exact artifact, and records its
  provenance before release promotion.

## Update

```bash
codex plugin marketplace upgrade codex-usage-sidebar
codex plugin add codex-usage-sidebar@codex-usage-sidebar
```

Start a new Codex task, then run the one-command repair flow from the installation guide.
