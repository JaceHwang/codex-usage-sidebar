# Codex Usage Sidebar v0.3.0

## Release assets and scope

- Windows x64: [`codex-usage-sidebar-v0.3.0-windows-x64-setup.exe`](https://github.com/JaceHwang/codex-usage-sidebar/releases/download/v0.3.0/codex-usage-sidebar-v0.3.0-windows-x64-setup.exe), with `WINDOWS-V030-SHA256SUMS.txt`.
- Windows signing state: `NotSigned`. This is a Windows 11 AMD64/x64-only setup; Windows ARM64 is not supported.
- macOS arm64: `codex-usage-sidebar-v0.3.0-macos-arm64.dmg` for Apple Silicon on macOS 14 or later.

Verify the Windows setup SHA-256 before launch. A matching digest permits the documented
SmartScreen continuation for **Unknown publisher**; a mismatching digest must not be run.

## Windows visual and behavior updates

- Places the compact quota indicator in the active task content header beside Codex's **Open location** control, with a validated narrow-window fallback.
- Keeps the overlay hidden for unknown UI Automation structures after an upgrade; the approved fallback requires official host, valid quota, and Codex build `151.0.7922.76`.
- Matches Codex light and dark themes and uses the same fixed quota spectrum as macOS.

## Validation boundary

This official `v0.3.0` publication promotes the exact Windows x64 and macOS arm64 candidate bytes
from the successful `v0.3.0` branch candidate run. Windows setup signing remains `NotSigned`; users
must verify SHA-256 before running it and should expect the SmartScreen **Unknown publisher** path.
The 130-case Windows manual matrix is incomplete, and local setup lifecycle validation is not
claimed for this publication. The Windows overlay hides itself for unknown or unsupported UI
Automation structures instead of guessing coordinates.

## Immutable macOS history

The macOS v0.2.3 application, its DMG, provenance, and release workflow are immutable history and
are not overwritten by this v0.3.0 Windows release.
