# Codex Usage Sidebar v0.3.0

Version 0.3.0 brings the macOS v0.2.3 quota experience to Windows while preserving the established macOS layout and visual language.

## Platforms

- Windows x64: Windows 11 on AMD64/x64. Windows ARM64 is not supported by this release.
- macOS arm64: Apple Silicon on macOS 14 or later.

## Windows visual and behavior updates

- Places the compact quota indicator in the active task content header beside Codex's **Open location** control, with a validated narrow-window fallback.
- Tracks window movement and resizing while hiding on unknown or incomplete UI Automation structures instead of guessing screen coordinates.
- Keeps the detail popover stable while the pointer moves from the indicator into the popover.
- Matches Codex light and dark themes and uses the same fixed quota spectrum as macOS.
- Aligns countdown typography and the compact `v0.3.0` badge with the macOS v0.2.3 popover.

The Windows setup candidate remains nonpublishable until the complete Windows 11 x64 real-device matrix and installer lifecycle checks are recorded and bound to the exact validated source commit.

The existing macOS v0.2.3 app, DMG, provenance, and release workflow remain frozen and are not overwritten by the v0.3.0 candidate pipeline.
