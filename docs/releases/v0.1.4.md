# Codex Usage Sidebar v0.1.4

Version 0.1.4 makes the quota control and its detail card feel native beside Codex's own titlebar
controls while adding clearer reset timing.

## Changed

- The compact quota label now uses larger, darker, semibold titlebar typography, with a bold
  percentage that retains the live quota color scale.
- The detail card now uses a theme-aware popover material, a softer native-style border, rounded
  corners, and the system window shadow.
- The next reset and every dated Bank entry include a live relative interval such as
  `8月16日 14:48（6天0小时）` or `8月13日 02:00到期（3天8小时）`.
- Long reset and Bank values wrap inside the compact 220-point card instead of being clipped.

## Update

```bash
codex plugin marketplace upgrade codex-usage-sidebar
codex plugin add codex-usage-sidebar@codex-usage-sidebar
```

Start a new Codex task after updating, or run the one-command repair from the installation guide.
