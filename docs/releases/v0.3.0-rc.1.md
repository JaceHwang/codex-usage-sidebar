`v0.3.0` release.

## Windows validation and trust boundaries

Windows support is Windows 11 AMD64/x64 only. Windows ARM64 is unsupported.
The setup signing state is `NotSigned`. Verify its published SHA-256 before
running it, and expect the Windows SmartScreen **Unknown publisher** warning.
Do not run a setup whose digest differs from `WINDOWS-V030-SHA256SUMS.txt`.

The 130-case Windows manual matrix is incomplete. This pre-release has passed
automated gates and the limited x64 smoke record only; it is not represented as
fully real-device validated.

Unknown or unsupported UI Automation structures hide the overlay; no coordinates are guessed.
Single-monitor scope is validated. Cross-monitor movement, cross-monitor DPI transitions,
and negative-coordinate placement are not claimed.

## macOS scope

The macOS candidate is arm64-only for Apple Silicon on macOS 14 or later. Its
provenance records the exact source, packaging commit, workflow run, and
candidate artifact. The DMG is not notarized, so macOS may require opening it
from Finder's context menu.
