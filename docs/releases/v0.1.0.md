# Codex Usage Sidebar v0.1.0

The first public release brings live Codex quota information into the desktop UI without modifying
the signed Codex application.

## Highlights

- Remaining quota and reset time beside the native sidebar controls.
- Automatic placement in the right-side titlebar group when the sidebar is collapsed.
- Theme-aware hover details for plan, period, Credits, and every Bank entry.
- Automatic hiding on Settings and completed non-main surfaces.
- Local-only quota transport through the Codex `app-server`.
- Upgrade-safe LaunchAgent installation with repair and uninstall commands.
- Human and coding-agent installation playbooks in English and Chinese.

## Install

```bash
codex plugin marketplace add Byctor/codex-usage-sidebar
codex plugin add codex-usage-sidebar@codex-usage-sidebar
```

Then start a new Codex task. Follow the [installation guide](../INSTALL.md) for macOS permission
setup and expected status output.

## Compatibility

- macOS 14 or later
- Apple Silicon
- Codex desktop for macOS
- Codex CLI with plugin marketplace support
