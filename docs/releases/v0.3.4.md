# Codex Usage Sidebar v0.3.4 Windows prerelease

The [v0.3.4 GitHub prerelease](https://github.com/JaceHwang/codex-usage-sidebar/releases/tag/v0.3.4)
contains a corrected Windows 11 AMD64/x64 installer built from `ec28ae97768bdb908cba5688b3d969371b4a0899`.
Windows ARM64 is not supported.

## Included fixes

- Ships a schema-v2 selector catalog instead of the incompatible legacy schema-v1 `device-test` catalog.
- Falls back to the built-in safe catalog when a packaged catalog is invalid, allowing the signed HTTPS
  compatibility updater to run instead of terminating the host during startup.
- Includes a P-256 public key, HTTPS compatibility-pack URL, and signed schema-v2 compatibility pack.

## Validation boundary

This is a `quick-prerelease`, not a formal stable Windows release. The package, embedded payload,
runtime tests, and signed compatibility pack passed local verification. The new 85-case Windows 11
x64 real-device matrix has not yet been completed for this build, so users should verify it on their
target Windows/Codex installation and report the result before stable promotion.

The setup is intentionally unsigned (`NotSigned`); verify `WINDOWS-V034-SHA256SUMS.txt` before launch.
Windows ARM64 is out of scope, and users must not disable Defender, SmartScreen, antivirus, or system policy.
