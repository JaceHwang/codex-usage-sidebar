# Codex Usage Sidebar v0.1.6

Version 0.1.6 prevents the quota control from returning to its legacy fallback position while
Codex rebuilds its accessibility tree.

## Fixed

- The companion retains the last valid Open Location element when a short accessibility scan
  returns fallback or only detects the right-pane boundary.
- A fresh Open Location result still replaces the retained element, so window and pane movement
  continue to update the exact 8-point gap.
- During a cold start, the control waits for the native anchor instead of briefly appearing at the
  old window-relative fallback position.
- Diagnostics now report the real first scan, including window geometry, without recording Codex
  interface or conversation text.

The 300-point native detail card and compact reset and Bank expiry format from v0.1.5 remain
unchanged.

## Update

```bash
codex plugin add codex-usage-sidebar@personal
```

The external companion can then be repaired with the one-command flow from the installation guide.
