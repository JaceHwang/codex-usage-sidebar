# Codex Usage Sidebar v0.1.5

Version 0.1.5 fixes the right-pane placement regression and makes the detail card's native surface
unambiguous in both Codex themes.

## Fixed

- When the right pane is open, the quota control now anchors to the central-content boundary and
  remains exactly 8 points before the pane instead of following the global Open Location button.
- Cached accessibility anchors expire after a short interval, allowing pane open, close, resize,
  and layout changes to correct themselves automatically.
- The detail card now uses AppKit's semantic `windowBackgroundColor` and `separatorColor`, a
  continuous 12-point corner, and the system panel shadow. This produces the native white surface
  in light mode and native dark surface in dark mode without relying on ineffective backdrop blur.

## Update

```bash
codex plugin add codex-usage-sidebar@personal
```

The external companion can then be repaired with the one-command flow from the installation guide.
