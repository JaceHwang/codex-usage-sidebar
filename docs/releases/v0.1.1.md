# Codex Usage Sidebar v0.1.1

This patch keeps the live Codex quota control in one stable place: the right side of the titlebar
on every confirmed main surface, whether the left sidebar is expanded or collapsed.

## Highlights

- Permanent right-titlebar placement on the main Codex surface.
- No dependency on the sidebar footer or profile-row anchor.
- The same theme-aware hover card with plan, period, Credits, and every Bank entry.
- Settings and other completed non-main surfaces still hide the control.
- Diagnostics and sidebar-state synchronization now report the normalized titlebar placement.

## Install or update

```bash
codex plugin marketplace add Byctor/codex-usage-sidebar
codex plugin add codex-usage-sidebar@codex-usage-sidebar
```

Start a new Codex task after installation. Existing installations can also run:

```bash
"$HOME/Library/Application Support/CodexUsageSidebar/sidebar-control.sh" repair
```

## Compatibility

- macOS 14 or later
- Apple Silicon
- Codex desktop for macOS
- Codex CLI with plugin marketplace support
