# Codex Usage Sidebar v0.1.7

Version 0.1.7 fixes a startup regression that could leave the quota control hidden when Codex's
accessibility tree temporarily returned no Open Location anchor.

## Fixed

- The quota control stays visible at a safe right-side fallback position when the native anchor is
  temporarily unavailable.
- The companion continues scanning and automatically returns the control to the exact 8-point gap
  before Open Location as soon as the accessibility tree is ready.
- The retained native anchor behavior from v0.1.6 remains active, so transient pane animations and
  renderer refreshes do not cause unnecessary fallback movement after the anchor is acquired.

The 300-point native detail card and compact reset and Bank expiry format remain unchanged.

## Update

```bash
codex plugin add codex-usage-sidebar@personal
```

The external companion can then be repaired with the one-command flow from the installation guide.
