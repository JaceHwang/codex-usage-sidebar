# Codex Usage Sidebar v0.2.1

Version 0.2.1 fixes live language switching when Codex has an explicit language selected in
General settings.

## Highlights

- Treats Codex's explicit Simplified Chinese, Traditional Chinese, or English selection as the
  authoritative language.
- Avoids falling back to a stale renderer locale after a manual language switch.
- Preserves Auto behavior by using the effective running renderer locale when no explicit override
  exists.
- Keeps unsupported languages mapped to English.
- Continues refreshing visible and pinned quota content without requiring a plugin reinstall.

## Resolution order

1. Explicit Codex desktop language override.
2. Effective locale of the running Codex renderer when language is Auto.
3. Codex Preferences during startup.
4. macOS preferred language during startup.

## Validation

The release adds regression coverage for explicit-over-Auto precedence, the real `[desktop]` TOML
layout, malformed and unrelated values, live configuration rereads, and Auto fallback behavior.
The release payload is promoted from the exact successful GitHub Actions artifact and recorded in
`assets/PROVENANCE.json`.
