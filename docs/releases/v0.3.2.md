# Codex Usage Sidebar v0.3.2

Released assets are available on the [v0.3.2 GitHub Release](https://github.com/JaceHwang/codex-usage-sidebar/releases/tag/v0.3.2).

## Assets

- macOS 14+ Apple Silicon: `codex-usage-sidebar-v0.3.2-macos-arm64.dmg`, `MACOS-V032-SHA256SUMS.txt`, and `MACOS-V032-PROVENANCE.json`;
- Windows 11 AMD64/x64: `codex-usage-sidebar-v0.3.2-windows-x64-setup.exe`, `WINDOWS-V032-SHA256SUMS.txt`, and `WINDOWS-V032-PROVENANCE.json`.

Verify the downloaded installer or DMG against its matching SHA-256 file before opening it. The Windows setup is unsigned and may display an expected **Unknown publisher** prompt after verification. Windows ARM64 is not supported.

## Highlights

- macOS and Windows use the shared local app-server quota, Token usage, account identity, localization, countdown, Credits, and Bank data contracts;
- seven-day Token usage, account fallback, theme-aware icon, GitHub footer link, and responsive titlebar placement are included;
- the current v0.3.2 card does not render a Tibo X entry;
- Windows accepts compatible Codex titlebar UIA structures without a fixed file-version allow list and fail-hides on unsafe structures;
- provenance verification now binds the bundled companion executable SHA-256 to its recorded metadata in CI.

## Validation boundary

macOS release/installer validation and CI passed. Windows source and packaging gates passed, but the full Windows real-device matrix remains incomplete. See [Windows v0.3.2 release and device gate](../WINDOWS-BETA.md) before interpreting the Windows asset as fully device-validated.
