# Codex Usage Sidebar v0.1.3

Version 0.1.3 removes the brief quota-control flicker that could occur after clicking the external
overlay.

## Fixed

- Companion activation now preserves the current overlay instead of treating it as a switch away
  from Codex.
- Activating Codex still reconciles and refreshes the quota immediately.
- Activating another application still hides the overlay as before.
- Regression coverage verifies all three activation decisions.

## Update

```bash
codex plugin marketplace upgrade codex-usage-sidebar
codex plugin add codex-usage-sidebar@codex-usage-sidebar
```

Start a new Codex task after updating, or run the one-command repair from the installation guide.
