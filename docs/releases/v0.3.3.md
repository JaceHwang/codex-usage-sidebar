# Codex Usage Sidebar v0.3.3 (local candidate)

This local candidate implements the dual quota presentation from the approved reference UI. It is
not published to GitHub yet.

## Highlights

- Decodes the official `primary` (5-hour) and optional `secondary` (7-day) rate-limit windows.
- Shows two independent percentage labels and gradient progress bars in the macOS AppKit and Windows WPF cards.
- Adds two-line titlebar summaries with the 5-hour window first and the 7-day window second.
- Adds localized table rows for the 7-day quota period and next reset while preserving Credits, Bank details,
  token usage, account identity, theme icons, and the GitHub footer link.
- Keeps the old single-window layout when Codex does not provide a secondary window.

## Local verification

macOS native suite: **276 tests, 0 failures**. Native visual fixtures cover Simplified Chinese,
Traditional Chinese, and English in Aqua and Dark Aqua appearances. The macOS arm64 candidate can be
packaged from the current `v0.3.2` development branch:

```bash
bash scripts/build-macos-v033-installer.sh
bash scripts/package-macos-v033-installer.sh
bash scripts/verify-macos-v033-installer-package.sh \
  ".dist/v0.3.3/macos/Codex Usage Sidebar Installer.app" \
  ".dist/v0.3.3/macos/codex-usage-sidebar-v0.3.3-macos-arm64.dmg"
```

The Windows core and WPF source are aligned with the same shared contract. Windows compilation,
installer packaging, UI Automation, DPI, and theme verification must be run on a Windows 11 AMD64/x64
host because this macOS host has no .NET SDK or WPF runtime.
