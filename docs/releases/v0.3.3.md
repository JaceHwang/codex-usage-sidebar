## Compatibility and safety

The installer embeds the schema-v2 selector catalog and a P-256 public key. It checks the HTTPS
compatibility pack before accepting a remote selector catalog; an unavailable or invalid update
keeps the packaged or previously validated catalog. Users do not edit `selectors.json` or perform
manual Codex-version adaptation.

The selector no longer rejects a Codex build solely because its file version changed. It still
requires a safe semantic UI Automation titlebar structure and hides the overlay when the structure
cannot be proven safe instead of guessing coordinates.

## Highlights

- macOS renders independent 5-hour and 7-day quota labels, gradient bars, and reset countdowns;
- the Token chart follows the longest available quota cycle, normally the seven-day secondary window;
- the macOS detail card keeps its titlebar anchor and fixed width while a centered footer grip
  smoothly resizes the scrollable details area;
- card content continues to include account identity, Credits, Bank expiry rows, theme-aware icons,
  localized Simplified Chinese/Traditional Chinese/English text, and the GitHub footer link.
