# Codex Usage Sidebar v0.1.8

Version 0.1.8 fixes a release-only visual regression caused by compiling the promoted companion
against macOS SDK 15.5 while the verified local build used macOS SDK 26.5.

## Fixed

- Release builds now run on the macOS 26 ARM64 runner with Xcode 26.5 selected explicitly.
- CI verifies that the packaged companion contains ARM64 code and is linked against macOS SDK
  26.5 before uploading an artifact.
- The final installed build therefore uses the same modern AppKit behavior as the locally verified
  build instead of activating legacy titlebar and popover compatibility behavior.

The always-visible fallback, exact 8-point Open Location gap, 300-point detail card, and compact
reset and Bank formatting remain unchanged.

## Update

```bash
codex plugin add codex-usage-sidebar@personal
```

The external companion can then be repaired with the one-command flow from the installation guide.
