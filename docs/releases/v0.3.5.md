# Codex Usage Sidebar v0.3.5

Published assets are available from the [v0.3.5 GitHub Release](https://github.com/JaceHwang/codex-usage-sidebar/releases/tag/v0.3.5).

## macOS assets

- Installer: `codex-usage-sidebar-v0.3.5-macos-arm64.dmg`
- Checksums: `MACOS-V035-SHA256SUMS.txt`
- Provenance: `MACOS-V035-PROVENANCE.json`

This macOS 14+ Apple Silicon maintenance release keeps the two quota rows aligned in the titlebar
and restores the explicit ` · ` separator between the percentage and reset time. The local macOS
companion, embedded marketplace payload, installer, and DMG are rebuilt from one exact source commit;
the provenance and checksum assets record the resulting digests.

The DMG is not notarized. Verify its SHA-256 before opening it. If Gatekeeper blocks the raw release
asset, right-click the installer in Finder and choose **Open**.

## Windows status

Windows is unchanged in this release. Download the independently validated Windows 11 AMD64/x64
setup from [v0.3.3](https://github.com/JaceHwang/codex-usage-sidebar/releases/tag/v0.3.3); Windows
ARM64 remains unsupported.

## Validation

- Swift package suite and titlebar-indicator regression coverage;
- local app-server probe, companion signing, bundle-version, plugin, and public-repository checks;
- arm64 installer code-signature verification and DMG mount verification.

The final source commit and asset SHA-256 are recorded in `MACOS-V035-PROVENANCE.json` and
`MACOS-V035-SHA256SUMS.txt` on the release page.
