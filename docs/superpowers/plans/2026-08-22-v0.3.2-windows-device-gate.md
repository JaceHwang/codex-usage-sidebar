# v0.3.2 Windows Device Gate Continuation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Continue the `v0.3.2` handoff by producing locally verified Windows x64 device-test evidence while keeping the branch nonpublishable until the complete real-device matrix passes.

**Architecture:** Reuse the existing Windows host/control and installer scripts from `ba70631`; build only the deterministic `device-test` payload, run the default-redacted UI Automation probe against the visible Codex client, and record exact verification evidence in the project board. No product-version bump, release setup, GitHub release, or macOS asset change is in scope.

**Tech Stack:** Windows 11 x64, .NET 8 SDK, WPF, PowerShell, Python, existing Windows solution and payload-manifest validators.

**Spec:** `docs/PROJECT_PROGRESS-v0.3.2.md` and `docs/WINDOWS-DEVICE-HANDOFF.md`

## Global Constraints

- Keep product/runtime version `0.3.1` as recorded by the v0.3.2 board; do not claim a v0.3.2 release.
- Keep all generated payloads and probe output outside tracked source paths, except for explicitly reviewed board/plan documentation.
- Keep the device payload status `device-test`, `realDeviceValidated=false`, and `publishableInstaller=false` until the complete matrix is captured and reviewed.
- Use the default-redacted probe; do not pass `--include-text` and do not store private Codex task content.
- Do not use the v0.3.0 release-setup builder, publish a setup asset, push GitHub, or alter macOS artifacts.

- [ ] **Step 1: Run the default-redacted probe**

```powershell
$probeRoot = Join-Path ([IO.Path]::GetTempPath()) 'codex-usage-sidebar-v0.3.2-probes'

if ($null -eq $control) { throw 'No control executable was produced.' }

if ($LASTEXITCODE -ne 0) { throw 'Default-redacted UIA probe failed.' }
```

Expected: exit code 0 and a report outside the repository; no raw UIA text is requested or stored.

- [ ] **Step 2: Validate report privacy and schema**


Expected: schema is readable and no raw-text capture flag is enabled.
