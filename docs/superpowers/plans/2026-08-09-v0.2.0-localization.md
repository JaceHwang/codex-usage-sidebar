# Codex Usage Sidebar v0.2.0 Localization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release v0.2.0 with Simplified Chinese, Traditional Chinese, and English UI that follows the effective language of the running Codex desktop app.

**Architecture:** A pure `SidebarCore` resolver maps process, Preferences, and macOS locale candidates into one of three display languages. Typed localized copy drives the existing formatters, while a read-only AppKit-side provider reads the final Codex `--lang` and refreshes language once per second without disturbing placement or pinned state.

**Tech Stack:** Swift 6, Foundation, AppKit, Darwin/libproc, XCTest, Bash lifecycle tests, Codex plugin cachebuster flow, GitHub Actions provenance promotion.

## Global Constraints

- Base plugin and companion version is exactly `0.2.0`; development installs use one `+codex.<cachebuster>` suffix.
- Effective locale precedence is running Codex `--lang`, Codex `Default/Preferences`, then the first macOS preferred language.
- `zh-Hans`, `zh-CN`, `zh-SG`, and bare `zh` map to Simplified Chinese.
- `zh-Hant`, `zh-TW`, `zh-HK`, and `zh-MO` map to Traditional Chinese.
- `en-*` maps to English; every other language maps to English.
- Codex, Bank, Credits, plan names, and version strings are not translated.
- The titlebar indicator remains exactly eight points before Open Location.
- Theme adaptation, quota colors, spectrum progress, hover preview, and click-to-pin remain intact.
- The official Codex app is never modified or re-signed, and process arguments are never persisted.
- The final release binary is the exact successful GitHub Actions artifact recorded in `assets/PROVENANCE.json`.

~~~swift
public struct QuotaDetailInteractionState: Equatable, Sendable {
    public private(set) var isPinned = false
    private var isPointerInside = false
    private var suppressHoverUntilExit = false

    public init() {}

    public var shouldShowDetail: Bool {
        isPinned || (isPointerInside && !suppressHoverUntilExit)
    }

    public mutating func updatePointerInside(_ inside: Bool) {
        if !inside { suppressHoverUntilExit = false }
        isPointerInside = inside
    }

    public mutating func togglePinned(pointerInside: Bool) {
        isPointerInside = pointerInside
        if isPinned {
            isPinned = false
            suppressHoverUntilExit = pointerInside
        } else {
            isPinned = true
            suppressHoverUntilExit = false
        }
    }

    public mutating func reset() { self = .init() }
}
~~~
