# v0.3.0-rc.1 Quick Prerelease Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish a public unsigned `v0.3.0-rc.1` GitHub pre-release with verified Windows x64 and macOS arm64 assets, without claiming the 130-case manual Windows matrix is complete.

**Architecture:** Add a strict `quick-prerelease` validation profile next to the unchanged `formal` profile. The quick profile has its own fixed-schema smoke evidence and is bound from frozen source `S`, through evidence-only packaging commit `P`, candidates, exact asset checks, and the public prerelease.

**Tech Stack:** Python 3.13, PowerShell 5.1-compatible scripts, .NET 8 WPF installer, pinned GitHub Actions, GitHub CLI 2.97.0+.

## Global Constraints

- Windows is Windows 11 AMD64/x64 only; reject Windows ARM64.
- Formal remains exactly `docs/validation/windows-v0.3.0.json`, 130 cases, tag `v0.3.0`, and `realDeviceValidated: true`.
- Quick is exactly `quick-prerelease`, uses `docs/validation/windows-v0.3.0-quick-prerelease.json`, tag `v0.3.0-rc.1`, and `realDeviceValidated: false`.
- Quick evidence contains only fixed redacted machine/smoke facts: no raw UIA names, screenshots, task content, credentials, free text, skips, or waivers.
- `P` may differ from `S` only in the chosen canonical evidence file. Unknown UIA means hidden overlay, never guessed geometry.
- Retain pinned Actions, `contents: read`, exact six-file staging, reparse/link rejection, exact run-ID downloads, and no `--clobber`.
- Build Windows x64 and macOS arm64 v0.3.0 assets; never change macOS v0.2.3 assets, tag, workflow, provenance, or Release.
- Public notes disclose unsigned setup, SHA-256/SmartScreen, incomplete manual matrix, x64-only support, and single-monitor scope.
