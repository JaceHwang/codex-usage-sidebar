# Codex Usage Sidebar v0.2.0 Localization Design

**Date:** 2026-08-09

**Status:** Proposed

**Scope:** Add Simplified Chinese, Traditional Chinese, and English UI localization while preserving the existing indicator placement, quota coloring, version badge, hover behavior, and click-to-pin interaction.

## Goals

- Release the plugin as `v0.2.0`.
- Match the language that the running Codex desktop app actually displays, including the final language selected when Codex is configured to use automatic language detection.
- Localize the titlebar indicator's date/time and every user-facing string in the quota detail popover into Simplified Chinese, Traditional Chinese, or English.
- Fall back to English for every unsupported Codex language.
- Detect a Codex language change without requiring the plugin to be reinstalled.
- Preserve the exact Open Location anchor relationship, eight-point titlebar gap, theme adaptation, quota color scale, version badge, hover preview, and click-to-pin behavior.

## Non-goals

- Translating Codex, Bank, plan names, or version strings.
- Adding a separate language selector to the plugin.
- Supporting languages beyond Simplified Chinese, Traditional Chinese, and English in v0.2.0.
- Modifying Codex application files or depending on undocumented UI scraping for language detection.

## Effective Language Resolution

The plugin must follow Codex's **effective** display language, not independently repeat Codex's automatic-language decision.

Resolution order:

1. Inspect only running Codex renderer/helper process arguments associated with the Codex user-data directory and read their `--lang=<BCP-47 tag>` value. This is the final locale selected by Codex after applying either an explicit language preference or automatic system matching.
2. If no running Codex process exposes a locale, read `intl.selected_languages` from Codex's Chromium `Default/Preferences` JSON and use its first language tag.
3. If Codex Preferences are absent, unreadable, or incomplete, use the first macOS preferred language.
4. Map unsupported or unrecognized language tags to English.

Language mapping:

| Effective tag | Plugin language |
| --- | --- |
| `zh-Hans*`, `zh-CN`, `zh-SG`, bare `zh` | Simplified Chinese |
| `zh-Hant*`, `zh-TW`, `zh-HK`, `zh-MO` | Traditional Chinese |
| `en*` | English |
| All other tags | English |

Language tags must be normalized case-insensitively with `_` and `-` treated equivalently. Script subtags take precedence over region subtags when both are present.

The provider will cache its last result and reevaluate it on the existing runtime reconciliation cycle at a throttled interval of one second. It updates the UI only when the mapped plugin language changes. Process inspection must remain in-process, read-only, and limited to Codex processes; it must not launch a shell or persist process arguments.

## Localization Architecture

Add a pure `SidebarCore` language layer:

- `CodexDisplayLanguage`: `.simplifiedChinese`, `.traditionalChinese`, and `.english`.
- `CodexLanguageResolver`: normalizes and maps candidate locale tags and applies source precedence.
- `QuotaLocalization`: typed localized copy and language-specific locale/date-format policy.

Add an AppKit/runtime provider that supplies locale candidates from the running Codex app, Codex Preferences, and macOS. File-system paths are injected so resolver and preference parsing can be tested without touching real user data.

Formatters receive `CodexDisplayLanguage` explicitly. They must not rely on `Locale.autoupdatingCurrent` for UI language, because the Codex language can differ from macOS after a manual override. The local time zone remains `TimeZone.autoupdatingCurrent`.

All copy remains compiled into the native companion. No network access is required for localization.

## Localized Copy

Representative copy:

| Meaning | Simplified Chinese | Traditional Chinese | English |
| --- | --- | --- | --- |
| Header title | `Codex 剩余额度` | `Codex 剩餘額度` | `Codex quota` |
| Plan | `套餐` | `方案` | `Plan` |
| Quota window | `额度周期` | `額度週期` | `Quota window` |
| Next reset | `下次重置` | `下次重設` | `Next reset` |
| Available Bank resets | `Bank 可用重置` | `Bank 可用重設` | `Bank resets available` |
| Bank expiry | `Bank 1到期时间` | `Bank 1到期時間` | `Bank 1 expires` |
| Bank details | `Bank 明细` | `Bank 詳情` | `Bank details` |
| Updated | `数据更新` | `資料更新` | `Updated` |
| No data | `暂无数据` | `暫無資料` | `No data` |

Other states, including available, unlimited, none, used, expired, missing expiry, just now, minutes ago, and hours ago, receive equivalent native copy in all three languages.

The compact relative interval inside parentheses remains language-neutral (`3d10h`, `42m`) to preserve the previously selected UI format and compact width. Parentheses follow the language's typography: full-width Chinese parentheses for both Chinese variants and ASCII parentheses for English.

## Date And Time Formatting

- Simplified Chinese: `8月16日 14:48`
- Traditional Chinese: `8月16日 14:48`
- English: `Aug 16, 14:48`

The titlebar indicator keeps its width-aware formatting tiers. If the full English month/date form does not fit, it falls back to the existing medium and narrow variants rather than expanding into or moving the Open Location control. The indicator's trailing edge remains exactly eight points before the resolved anchor in every language.

The detail popover retains its current width unless localized text requires the existing wrapping/scrolling layout. Header layout must reserve room for the longer localized title, the `v0.2.0` badge, and the colored remaining percentage without overlap or clipping.

## Runtime Behavior

When the effective Codex language changes:

1. Resolve the new `CodexDisplayLanguage`.
2. Reformat the current in-memory quota snapshot immediately; do not wait for a network refresh.
3. Update the titlebar indicator and any currently visible or pinned popover in place.
4. Preserve hover/pinned interaction state and panel geometry.

If locale detection temporarily fails, retain the last valid mapped language for the current companion process. On a cold start with no valid source, use English.

## Versioning

- Change `.codex-plugin/plugin.json` base version to `0.2.0`.
- Continue deriving `CFBundleShortVersionString` from the manifest through the build pipeline.
- Display the existing version capsule from `Bundle.main` so it automatically shows `v0.2.0`.
- Add regression coverage that the manifest version, built app version, and displayed short version source remain synchronized.

## Upgrade Compatibility

Language detection must not patch or sign the official Codex app. It depends on stable external signals in this order: the effective Chromium `--lang` process argument, Chromium Preferences, and macOS preferences. If Codex changes its desktop implementation and removes one signal, the remaining fallbacks keep the plugin usable.

The release must retain the existing stable companion signing and CI provenance promotion flow. The downloadable v0.2.0 asset must be the exact CI-built artifact tested and promoted to `main`, preventing the prior local-build-versus-reinstall regression.

## Test Strategy

Unit tests:

- Locale normalization, script/region precedence, and all supported/unsupported mappings.
- Resolution precedence across process, Preferences, and system candidates.
- Missing, corrupt, and partially written Preferences files.
- Simplified Chinese, Traditional Chinese, and English formatter output for indicator, quota rows, Bank rows, credit states, freshness, missing data, and past/future intervals.
- Header layout for the longest localized title with badge and remaining percentage.
- Exact eight-point Open Location gap across all three languages and indicator width tiers.
- Runtime language changes reformat the current snapshot without changing interaction state.
- Version synchronization at `0.2.0`.

Integration and release checks:

- Run the complete Swift test suite and shell regression suite.
- Build the signed production companion and validate SDK and bundle metadata.
- Install the cache-busted local v0.2.0 build and verify the running companion reports the correct bundle version and effective language.
- Verify the actual titlebar indicator and popover in each supported language using controlled locale fixtures or runtime injection, without permanently changing the user's Codex preference.
- Verify hover preview, click-to-pin, second-click dismissal, theme adaptation, quota colors, Open Location gap, and Bank detail rendering after localization.
- Publish through the source-build-provenance-promotion workflow and verify the installed release asset hash matches the CI artifact.
