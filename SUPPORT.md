# Support

- Installation and permissions: [docs/INSTALL.md](docs/INSTALL.md)
- Common failures: [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md)
- Bugs: [open a bug report](https://github.com/Byctor/codex-usage-sidebar/issues/new?template=bug_report.yml)
- Feature ideas: [open a feature request](https://github.com/Byctor/codex-usage-sidebar/issues/new?template=feature_request.yml)
- Security issues: use [private vulnerability reporting](SECURITY.md)

When asking for help, include versions and sanitized diagnostic output. Never post account tokens,
private keys, or unrelated desktop screenshots.
